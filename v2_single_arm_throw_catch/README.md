# v2 — Stage 2：单臂杯子抛球 + 两点自抛自接

一台 UR5e 加 v1 的杯子，自己把球抛出去、再接住，循环往复。分两个实验：

- **实验 A（`throw_test.py`）**：抛球特性。180°/s 关节速度限制下能抛多高、多远，离手误差多大。
- **实验 B（`juggle_loop.py`）**：单臂单球，在两点 A、B 之间交替自抛自接，统计连续接住次数。每个循环里手臂要做的事
  （抛 → 在飞行时间 F 内赶到接球位 → 接 → 托球到下一次抛球起点 → 抛）和双臂 S1 模式里每只手臂要做的完全一样。

没有强化学习，全部是经典方法。v1 保持不变；UR5e mesh 已移到仓库根目录 `assets/`，各阶段共用。

## 运行（在仓库根目录）

```bash
# 实验 A
uv run python v2_single_arm_throw_catch/throw_test.py --trials 10 --calibrate          # 全部扫描（约 5 分钟）
uv run python v2_single_arm_throw_catch/throw_test.py --mode linewhip --F 0.5 --d 0.4 --trials 3 --calibrate --viewer
uv run python v2_single_arm_throw_catch/throw_test.py --mode whip linewhip --F 0.5 --d 0.4 --video videos/

# 实验 B
uv run python v2_single_arm_throw_catch/juggle_loop.py                                 # 10 次 x 最多 20 次接球
uv run python v2_single_arm_throw_catch/juggle_loop.py --obs-noise 0.005               # 5 mm 观测噪声
uv run python v2_single_arm_throw_catch/juggle_loop.py --runs 1 --viewer               # 实时观看（默认 0.5 倍速）
uv run python v2_single_arm_throw_catch/juggle_loop.py --runs 1 --cycles 6 --video videos/loop.mp4
```

`--viewer` 打开 MuJoCo 窗口，`--speed` 调播放速度；macOS 上用 `mjpython` 代替 `python`。开头会先花几秒做规划和校准。

## 抛球原理

杯子没有可以松开的东西：球靠在杯底，**杯子沿杯轴方向的减速度一旦超过重力，杯底就不再托住球，球自己飞出**。
离手速度就是那一刻杯底（`ball_seat`）的速度。判据写成"比力" f = a_seat − g：只要 f·杯轴 > 0 球就压在杯底，f·杯轴 ≤ 0 的第一刻即离手。

三种抛球动作共用同一个速度曲线（路径速度按 smoothstep 先加速 `t_acc` = 0.15 s、再减速 `t_dec` = 0.12 s），区别在路径：

| 动作 | 路径 | 特点 |
|---|---|---|
| `translate` 平移抛 | 杯底沿直线、杯子姿态不变 | 离手最干净；但杯子不能转，wrist_1 必须抵消前臂的转动，上臂、前臂都只能转 π rad/s，杯速理论上限 π(0.425 + 0.392) ≈ 2.57 m/s，且只在手臂水平伸直那一瞬间 |
| `whip` 甩臂抛 | 关节空间直线（shoulder_pan + 三个平行的俯仰关节） | 俯仰关节转速沿链叠加，快；但杯底走弧线，向心效应把球压在杯壁上 |
| `linewhip` 直线甩臂抛 | 杯底沿直线、杯子可以转（同 whip 的 4 个关节） | 保留 whip 的速度，杯底没有向心负载 |

离手点搜索（`ThrowPlanner.plan`）：在工作空间网格上做 IK（杯轴对准加速峰值时的比力方向，使球在加速时居中），按离手速度所需的关节速度排序，
对最好的若干候选生成整段轨迹并逐项检查：

- 关节速度 ≤ 0.9 × 180°/s（规划余量）；
- 逆动力学前馈力矩 ≤ 0.8 × 执行器上限（逆动力学在**关闭接触**的模型副本上算，否则碰撞姿态的接触力会被当成关节力矩）；
- 关节范围、伺服指令范围（ctrlrange）、自碰撞 / 地面碰撞；
- 加速段球一直压在杯底、不提前离手；离手后球从杯口出去时不擦杯沿。

实验 B 额外用到三个选项：限定离手区域（`region`）；"只因离手相关的解析检查被拒"的候选交给一次物理回放复核（`verifier`）；
按"抛完后手臂多快能到接球位"排序（`rank`），校准失败时尝试下一个候选（`finalize`）。

**180°/s 硬约束**：MuJoCo 本身没有关节速度上限。规划时留 10% 余量；仿真中每一步检查**实际**关节速度，超过 π rad/s 即判失败（`simcore.JointSpeedGuard`）。

**跟踪控制**：沿用 Menagerie 的位置伺服 `force = kp(ctrl − q) − kd·q̇`，令 `ctrl = q_d + (kd/kp)·q̇_d + τ_ff/kp`，
τ_ff = M(q_d)·q̈_d + c(q_d, q̇_d) 由逆动力学给出（v1 只有 M·q̈；抛球速度下科氏 / 离心项不能忽略）。

**仿真校准（`calibration.py`）**：用球居中的一次回放测出实际离手 (t, p, v)，算出"从实际离手状态正好在目标时刻到达目标点"所需的速度，
按差值修正指令速度，在同一离手构型上重建轨迹，迭代到误差 < 2 mm（或 < 10 mm 且再修正会违反约束）。
**这相当于把仿真器本身当作完美模型**，是一个很强的经典基线，报告里必须如实说明；以后灵巧手阶段的 RL 修正应与它对比。

## 实验 A：抛球特性（`throw_test.py`，原始输出 `results/throw_test.txt`）

目标："同一高度、沿 +y 方向 d 米外、离手 F 秒后落到"，即离手速度 v = (d/F)·ŷ + (gF/2)·ẑ。每种情况 10 次，
球在杯底的初始位置随机偏移 ≤ 10 mm（各情况用同一组偏移）。"miss" = 目标时刻球心与目标点的距离，即接球臂需要吸收的误差。
raw = 用解析离手预测规划；cal = 仿真校准之后。表中为"均值 / 最大值"。

**可行范围**（规划时关节速度 ≤ 0.9 × 180°/s、前馈力矩 ≤ 0.8 × 上限）：

| | d = 0 | d = 0.2 m | d = 0.4 m |
|---|---|---|---|
| translate | 仅 F = 0.35 s | 全部不可行 | 全部不可行 |
| whip | F = 0.35–0.45 s | F = 0.40–0.50 s | F = 0.45–0.50 s |
| linewhip | F = 0.35–0.45 s | F = 0.40–0.50 s | F = 0.45–0.50 s |

**离手精度**（代表性情况，完整结果见 `results/throw_test.txt`）：

| 情况 | 版本 | 离手时刻误差 | 离手速度误差 | miss | 球离手时碰杯壁 |
|---|---|---|---|---|---|
| translate d=0, F=0.35 | raw | 2.9 / 5.0 ms | 1.4 / 1.6 % | 14 / 18 mm | 0 % |
| whip d=0.4, F=0.5 | raw | 37 / 38 ms（晚） | 8.9 / 9.3 % | 99 / 104 mm | 100 % |
| whip d=0.4, F=0.5 | cal | 校准失败 | | | |
| linewhip d=0.4, F=0.5 | raw | 8.8 / 12 ms | 3.2 / 3.3 % | 34 / 36 mm | 100 % |
| linewhip d=0.4, F=0.5 | cal（4 次修正） | 1.6 / 3.0 ms | 0.4 / 1.0 % | 5.0 / 12.8 mm | 100 % |
| linewhip d=0.2, F=0.45 | cal（2 次修正） | 0.8 / 2.0 ms | 0.3 / 0.7 % | 3.2 / 6.0 mm | 100 % |
| linewhip d=0, F=0.40 | cal（2 次修正） | 0.0 / 0.0 ms | 0.2 / 0.3 % | 1.2 / 2.3 mm | 100 % |

- linewhip 的 7 个可行情况全部校准成功，校准后平均 miss 1–7 mm、最大 13 mm；关节速度 0.47–0.87、前馈力矩 0.46–0.76（力矩已成为主要约束，实际执行器力最高 0.85 × 上限）。
- whip 的 8 个可行情况中 7 个校准失败、1 个勉强通过（miss 14 / 26 mm）：球顺着杯壁滑出，离手晚 30–55 ms、慢 7–11 %，并带侧向速度，修正量所需的关节速度超出余量，迭代也不收敛。
- translate 本身已经很准（1.4 %），校准反而因关掉解析的杯沿检查出现 2/10 次回碰（RECONTACT），不需要校准。
- linewhip d=0、F=0.35 有 2/10 次回碰（球离手后又碰到杯沿）。

## 实验 B：单臂两点自抛自接（`juggle_loop.py`，原始输出 `results/juggle_loop_noise*.txt`）

**设置**：A = (0.6, −0.075, 0.55) m，B = (0.6, 0.075, 0.55) m（球心，相距 0.15 m），F = 0.4 s。
两个方向的抛球离线规划 + 校准：离手点限制在抛出点 ±(8, 8, 15) cm 内，按"抛完后到接球位的估计时间"排序（约 0.18 s）。
每次运行最多 20 次接球，10 次运行（不同的初始球位置），观测频率 100 Hz。

**每个循环**：
1. 抛出前按校准后的名义离手状态预先规划接球（v1 的接球规划器，接球逼近从抛球动作结束时开始）；
2. 离手后观测、每 50 ms 重新拟合，预测接球点移动 > 5 mm 就重新规划（同 v1）；
3. 接住判定：球在杯腔内，接球动作结束后相对杯子速度 < 0.05 m/s 持续 0.1 s；
4. 托球到下一次抛球起点（关节速度 ≤ 0.8π、加速度 12 / 20 rad/s²），静置 0.2 s 后抛出。

接球规划参数相对 v1 的修改：大关节加速度上限 15 → 40 rad/s²、腕关节 25 → 60 rad/s²（每段逼近都检查前馈力矩 ≤ 0.9 × 上限），
min_wait 0.10 → 0.05 s，earliest_catch 0.15 → 0.10 s。

| 观测噪声 | 达到 20 次的运行 | 连续接住次数（中位数 / 最少） | 失败 | 接球前剩余等待时间（均值 / 最小） | 每次接球重规划 |
|---|---|---|---|---|---|
| 0 | 10 / 10 | 20 / 20 | — | 80 / 23 ms | 1.6 |
| 5 mm | 10 / 10 | 20 / 20 | — | 50 / 20 ms | 4.0 |
| 10 mm | 5 / 10 | 15 / 0 | 掉落 2，球打到手臂 3 | 41 / 20 ms | 3.9 |

各噪声水平下共同的数字：离手时刻误差均值 ≈ 1.8 ms（最大 4 ms），离手速度误差均值 11–15 mm/s（最大 27 mm/s），
离手到入杯 ≈ 0.39 s，入杯相对速度 ≈ 1.7 m/s（最大 2.3），停留（入杯 → 下一次离手）≈ 1.16 s，即循环周期 ≈ 1.55 s。
实际关节速度峰值 0.87 × 180°/s（10 mm 噪声时 1.00，见局限），执行器力峰值 0.59–0.70 × 上限。

## 发现与局限

1. **平移抛对侧向抛没用**，与理论上限一致；**关节空间甩臂抛**的球会贴杯壁离手、无法校准；**直线甩臂抛**兼顾速度和离手精度，是后续阶段用的抛法。
2. **在 180°/s 下，同一只手臂的离手点和接球点最多相距约 0.15 m（F = 0.4 s）**。d = 0.25 m 时接球臂来不及赶到（探索记录见开发过程，未存档）。
   对 S1 的含义：两臂之间的距离要靠球飞，每只手臂自己的抛点和接点要靠得很近；而且抛球点的选择必须"考虑整个循环"——
   只追求抛球速度会让手臂停在离接球位很远的伸展姿态。
3. **用到的速度和力矩都接近上限**：抛球关节速度 0.84–0.86，接球逼近大关节加速度 40 rad/s²。换成更重的灵巧手后余量会更小。
4. **仿真校准 = 完美模型**。离手误差小很大程度上来自这一点；离手点、目标点不变（两点循环）时可以离线做，S1 也是如此，但这不是对未知物体或未知接触的鲁棒性。
5. **球离手时几乎总碰到杯壁**（linewhip 80–100 %），误差靠校准吸收，没有从机理上消除。
6. **接球规划器仍用 v1 的关节速度上限 π（没有 0.9 余量）**：10 mm 噪声时频繁重规划，实际关节速度峰值四舍五入后为 1.00 × 180°/s，虽未触发超速判定，但已没有余量。
7. **停留时间约 1.16 s**：托球更快会让球在抛出前停不稳（离手误差升到 ~250 mm/s）。按 Shannon 定理（F = V），停留时间不影响 S1 的可行性，只影响节奏。
8. **Menagerie 的位置伺服严重过阻尼**（kd/kp = 0.2 s）：受扰后回到期望位置较慢，跟踪主要靠前馈。
9. 10 mm 观测噪声下成功率降到 50 %，失败发生在后期重规划（剩余等待只有 ~20 ms）时；改进方向：更早锁定、滤波、或以名义轨迹为先验的加权拟合。
