# v4 — Stage 4：UR5e + LEAP 灵巧手（E1 握持 / 离手测试，E2 张开手指抛球）

杯子阶段的双臂实验（v3）已暂停（见 `git stash list`），项目直接转到灵巧手。v4 的第一步 E1 只回答一个问题：
**LEAP 手装在 UR5e 上，能否在抛球级别的加速度下握住一个 juggling 尺寸的球，并在不握时让它离手？**
没有强化学习，也还没有真正的抛接。

## 文件

| 文件 | 内容 |

## 运行（在仓库根目录）

```bash
uv run python v4_hand_grasp/grasp_test.py --a-up 2 3 --a-down 0.5 1.5 3
uv run python v4_hand_grasp/grasp_test.py --images v4_hand_grasp/results     # 另存三种手型的截图
uv run python v4_hand_grasp/hand_throw.py                                    # E2 参数扫描（约 3 分钟）
uv run python v4_hand_grasp/hand_throw.py --tilt 20 --heading 90 --t-open -0.02 0.02 --T-open 0.03
uv run python v4_hand_grasp/hand_throw.py --t-open 0.02 --T-open 0.03 --trials 1 --video videos/   # 0.25 倍速录像
```

## 球的规格（按真实 juggling 用球、与手的大小匹配）

| | 人手 | LEAP 手 |
|---|---|---|
| 手的大小 | 1 | 约 1.3 倍人手（Shaw et al., RSS 2023："similar in size to Allegro and ∼30% larger than a human hand"） |
| 常用 juggling 球直径 | 65–67 mm（成人标准 beanbag） | **85 mm**（= 65 mm × 1.3） |
| 球的质量 | 120 g（零售商称最标准、最常用） | **120 g**：LEAP 的握力与人手相当（拉脱力 19.5 N，论文称"超过人手"），所以不按体积放大（按体积会到约 260 g） |

接触参数沿用 v0–v2 的球：`solref=(0.003, 0.5)`，柔软、低回弹，像沙包。

## 模型设置

| 项目 | 值 | 说明 |
|---|---|---|
| 手的质量 | 0.746 kg（模型） | 实物 595 g（论文）。模型偏重约 25%，偏保守 |
| 手指执行器 | 位置伺服 kp = 3，**力矩上限 ±0.5 N·m** | Menagerie 模型没有力矩上限。LEAP 用 Dynamixel XC330-M288-T，电流上限 600–750 mA（论文）；0.5 N·m 是该电流下的保守估计，**待核实** |
| 重力补偿 | 手的所有刚体 `gravcomp=1` | 真实机械臂控制器会补偿负载重力 |
| 手指尺寸 | 根部间距：食指到无名指 91 mm；手指长约 0.11–0.12 m | 从模型中测得 |

## 三种手型

| 手型 | 关节目标 | 说明 |
|---|---|---|
| flat 平掌 | 全 0 | 参照组 |
| cradle 托球 | 手指 mcp = pip = 0.8、dip = 0.48；拇指 th_cmc = 1.2 | 小规模搜索得到：球在掌心时，手指一侧、拇指一侧、掌根一侧都有"墙"（在这些方向移动 6–34 mm 就会碰到）。**LEAP 没有小指，无名指一侧是敞开的**（移动 60 mm 都碰不到） |
| grasp 握球 | 手指 1.2 / 1.2 / 0.72；拇指 th_cmc 1.2、th_mcp 0.5 | 指令越过接触位置：三根手指、拇指和手掌同时接触球，舵机以力矩上限压住球。更紧的手型（th_cmc 1.6–1.8）会把球从敞开的一侧挤出去；直接以闭合手型放球也会把球弹开，所以要先托住，再收紧 |

## E1 结果（`results/grasp_test.txt`）

测试：ready 姿态（掌心朝上），球在手型中静置 1 s，然后手**竖直向上平移、姿态不变**（关节路径由 6 维任务 [z; 0] 积分得到）。
速度曲线：先以峰值加速度 a_up 加速到 0.9 m/s，再以峰值减速度 a_down 停下。
球离开手超过 20 ms 判为 THROWN（被抛出）；否则为 HELD（握住）。

| 手型 | a_up | a_down = 0.5 g | a_down = 1.5 g | a_down = 3 g | 握持时球在掌中的滑移 | 手指力矩 / 上限 |
|---|---|---|---|---|---|---|
| flat | 2–3 g | HELD | THROWN（空中约 115 ms） | THROWN（约 150 ms） | 1–3 mm | 0.33–0.50 |
| cradle | 2–3 g | HELD | THROWN（约 115 ms） | THROWN（约 150 ms） | 1–3 mm | 0.19–0.28 |
| grasp | 2–3 g | HELD | **HELD** | **HELD** | 1.1–1.2 mm | 1.00（按设计压到上限） |

- 手臂关节速度峰值 0.88–0.90 × 180°/s：这个姿态下竖直平移约 1 m/s 就接近上限，和 v2 的平移抛结论一致。
- 手臂执行器力峰值 0.74 × 上限，出现在 shoulder_lift（3g 向上加速时）。腕部 wrist_1 为 0.41 × 上限（28 N·m），手加球的负载可以承受。

**结论**：
1. 握球手型能在 3g 加速 / 3g 减速下握住 120 g 的球，滑移约 1 mm。
2. 平掌和托球手型在减速度超过 1g 时让球离手，与杯子的离手机理相同。

因此，用这只手抛球有两种离手方式可选：
- 像杯子一样靠减速度离手（托球手型）；
- 握住加速，再在设定时刻张开手指离手（握球手型）。后者真正体现 grasping，也是下一步 E2 要研究的。

## 局限 / 待办

- 手指力矩上限 0.5 N·m 是估计值，需要用 XC330-M288-T 的规格和 LEAP 的电流设置核实。
- 只测了竖直平移。侧向或倾斜的加速度、手的转动（甩臂）还没测。托球手型在无名指一侧没有遮挡，侧向负载朝那边时会怎样，需要专门测试。
- 握球时手指一直压在力矩上限：真实舵机长时间堵转会发热（论文中额定连续力矩约为堵转力矩的 20%），实际应只在加速阶段收紧。

## E2：握住加速、按时刻张开手指抛球（`hand_throw.py`）

**动作**：
- 球先在托球手型里放好，再收紧成握球手型。
- 法兰沿直线运动（手的姿态不变，`handsim.LineStroke`）：以 3g 加速到 V，峰值速度时法兰位于 (0.85, 0, 0.30)、掌心朝上，然后以 3g 减速停下。
- 手指从握球手型张到平掌（关节目标线性插值），由**两个参数**描述：
  - `t_open`：开始张开的时刻，相对峰值速度（负值表示在峰值之前）；
  - `T_open`：张开所用的时长（舵机受力矩上限限制，实际可能更慢）。
- 手指松开、且手的减速度超过 1g 时，球就离手。
- 离手速度上限：这个姿态手臂伸直，竖直平移最快约 2 m/s（扫描结果）。V = 1.7 m/s 时手臂关节速度为 0.82 × 180°/s。

**随机扰动**（衡量重复性）：球在掌中初始位置 ±3 mm、张开起始时刻抖动 ±3 ms、手指目标 ±0.02 rad。每组 10 次。

**竖直抛结果**（`results/hand_throw_vertical.txt`，均值 ± 标准差）：

| t_open | T_open | 离手（峰值后） | 球速 / 手速 (m/s) | 方向偏差 | 自转 | 抛高 |
|---|---|---|---|---|---|---|
| −40 / −20 ms | 10–60 ms | 9–10 ms | 1.66–1.69 ± 0.01 / 1.67–1.69 | 0.6–1.5° | 0.4–1.0 rad/s | 141–145 ± 2 mm |
| 0 ms | 10 ms | 7.1 ± 3.8 ms | 1.71 ± 0.05 / 1.67 | 1.4 ± 1.0° | 1.6 rad/s | 149 ± 9 mm |
| 0 ms | 30 ms | 6.8 ± 1.6 ms | 1.71 ± 0.01 / 1.67 | 1.1° | 1.2 rad/s | 149 ± 2 mm |
| +20 ms | 10 / 30 / 60 ms | 25 / 28 / 33 ms | 1.47 / 1.43 / 1.33 ± 0.03–0.05（手 1.40 / 1.34 / 1.22） | 1.2–2.1° | 0.9–1.3 rad/s | 111 / 105 / 90 ± 5–7 mm |
| +40 ms | 10 / 30 / 60 ms | 44 / 48 / 54 ms | 0.98 / 0.88 / 0.74 ± 0.04–0.06（手 0.88 / 0.78 / 0.60） | 1.8–2.6° | 1.1–1.3 rad/s | 49 / 40 / 28 ± 4–6 mm |

**发现**：
1. **在峰值之前张开**（t_open ≤ 0）时，球在减速度超过 1g 时自然离手（峰值后约 7–10 ms），速度等于手速，机理和杯子相同，t_open 几乎不起作用。
2. **在峰值之后张开**时，手指在减速段继续握住球，离手被推迟到 t_open 加 5–14 ms。离手速度随 t_open、T_open 单调下降（1.7 → 0.7 m/s），**张开时刻成为控制抛速的手段**，这是靠 grasping 实现的离手控制。
3. **球速比离手瞬间的手速快 0.07–0.14 m/s**（张开时手指与球的相互作用），解析模型不容易算准。这正是之后 RL 修正的切入点。
4. **重复性**：速度标准差 0.01–0.06 m/s，方向约 1°，抛高 1–9 mm。t_open = 0、T_open = 10 ms 最不稳定，因为恰好处在"减速度离手"和"手指离手"两种机理的交界。

**斜向抛**（偏离竖直 20°，`results/hand_throw_tilt20.txt`；t_open = −20 / +20 ms，T_open = 30 ms）：

| 偏斜方向（手掌坐标） | V | 结果 | 方向偏差 | 侧向速度 |
|---|---|---|---|---|
| 无名指侧（敞开的一侧） | 1.7 m/s | 10/10 抛出 | 1.7–1.8° | 45–49 mm/s |
| 拇指侧 | 1.7 m/s | 10/10 | 1.0–1.2° | 26–35 mm/s |
| 指尖方向 | 1.0 m/s | 10/10 | 2.7–3.1° | 34–45 mm/s |
| 掌根方向 | 1.2 m/s | 10/10 | 3.6–4.0° | 60–72 mm/s |

握球手型在四个方向的侧向负载下都能握住，球不会提前掉出。朝指尖、掌根方向，在这个姿态下需要手臂伸缩，1.7 m/s 会超速（1.33 / 1.15 × 180°/s），所以用了较低的速度。

**E2 的局限**：
- 只有抛，没有接；离手点固定在一个姿态；
- 手的姿态在运动中不变（平移），没有用甩臂；
- 手指张开是关节目标的线性插值，没有对每根手指单独设时刻；
- 手指力矩上限 0.5 N·m 仍待核实；
- 离手精度没有和杯子在相同条件下直接对比。
