# 单球接球策略对照

PPO 与 SAC 各使用三个训练种子、每种子 4,096 个控制步；仅按验证集选择检查点。
验证种子为 90000–90009；测试种子为 140000–140019。

固定残差在全部回合请求同一个四维向量；名义反馈、接触权限、限幅和变化率限制仍生效。
候选为零残差，以及三个 PPO 各自的初始输出和验证接触阶段请求均值；参数与选择均不使用测试结果。

常数沿用安全优先的验证评分，同分时优先较早候选；零残差列在首位。固定对照复用 PPO 训练资产，不单独比较参数搜索成本。

选定常数：`ppo_seed2_contact_mean`；归一化请求为 `[0.1651602286603874, -0.05065660785848701, 0.24524226321905546, 0.18064974746487747]`。

所有策略复用相同场景；三个训练种子的汇总不代表新增独立测试场景。

## 结论与范围

经典控制器、固定残差及两个 RL 算法的结果用于判断是否值得继续训练；候选筛选不触发控制器替换。
本测试未显示任一算法在全部训练种子上稳定超过固定残差。后续保留经典控制器和固定残差对照，暂不据此扩展三球 RL。
本比较仅覆盖一种有限预算配置，不能判定 SAC 或 PPO 的普遍优劣。
固定残差仅搜索上述有限候选；策略实时反馈的额外收益仍需结合反馈消融判断。
任务仅为下降单球的接稳，不包含主动抛球、双球或完整三球任务。
